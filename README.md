# 搜应用

一个离线的 Android 应用搜索工具：输入中文、英文或拼音，点一下就打开本机应用。

## 为什么做

在系统语言为英文的荣耀手机上，大众点评的应用名是 “Dianping”。系统自带的搜索只按当前语言的应用名查找本机应用，搜“点评”时找不到它，只显示应用市场的卡片；如果应用有新版本，按钮还是“更新”而不是“打开”。

搜应用同时索引每个应用的简体中文名、英文名、全拼和拼音首字母，所以 `点评`、`dianping`、`dzdp` 都能找到它。

## 特点

- 搜索结果只有本机应用，不含商店内容或广告
- 不申请联网权限，没有第三方依赖，安装包约 68KB
- 搜索框贴着键盘，最佳结果紧贴搜索框，按键盘的前往键打开第一项
- 搜索框为空时，最近打开的应用排在最下面
- 入口：桌面图标、桌面小组件、快捷开关

## 接管荣耀桌面的下滑手势

荣耀桌面下滑时发出的是隐式链接 `honorsearch://com.hihonor.search/home`，本应用声明了同样的链接。安装后在桌面下滑，系统会弹出选择框，选“搜应用”和“始终”即可。

不需要 root，也不会停用或修改系统搜索。想换回去时，在系统设置里清除搜应用的默认打开方式，再在选择框里选回系统搜索。

## 构建

需要 JDK 21 和 Android SDK（compileSdk 35），最低支持 Android 12。

```sh
./gradlew assembleRelease
```

未配置签名属性时，使用默认调试密钥签名。

## 测试情况

在一台荣耀折叠屏手机（MagicOS 10 / Android 16）的外屏上测试过搜索、打开应用和下滑接管。快捷开关、桌面小组件、深色模式和折叠内屏尚未测试，其他品牌的手机也没有测试。
